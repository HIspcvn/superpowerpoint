# PowerPoint review rubric

Use the brief and actual audience as the standard. This rubric is a decision aid, not a universal numeric score or reason to redesign an otherwise adequate deck.

| Dimension | Questions that affect delivery |
| --- | --- |
| Intent | Does the deck answer the requested question and support the audience's decision or understanding? |
| Narrative | Does each slide have a useful purpose? Are conclusions supported without unexplained jumps? |
| Facts and data | Do claims match their sources? Do values, totals, units, dates, categories, and chart encodings agree? |
| Readability | At intended viewing size, can the audience read titles, body text, data labels, and relevant source notes? |
| Layout | Are any elements clipped, unintentionally overlapping, misaligned, awkwardly wrapped, or cut by a crop? |
| Visual hierarchy | Is the main point visible and the reading order clear? Are color and emphasis meaningful and consistent? |
| Template fidelity | Does the deck retain the requested ratio, brand, fonts, logos, recurring geometry, and appropriate layouts? |
| Editability | Are text, shapes, required charts, and tables native? Are chart series data and workbooks consistent? |
| Preservation | Did editing retain unrelated slides, notes, links, data, animation, media, and other required features? |
| Language | Is the requested language consistent, including Vietnamese diacritics, proper names, terms, and number/date formats? |

## Severity

- **Blocking:** Corrupted/unopenable file, misleading data or unsupported critical claim, missing required content, unreadable key message, or loss of a required editable/playback feature. Fix before calling the requested work complete.
- **Material:** A visible issue that hinders comprehension, violates a stated template requirement, or causes a likely presentation/editing problem. Correct within scope or explicitly describe the unresolved limitation.
- **Minor:** Small spacing or style variation without meaningful audience impact. Fix if proportionate; do not expand a narrow edit into a broad redesign.

## Evidence record

Use a concise statement such as:

```text
Structural: 8 slides inspected; requested native chart on slide 2 and table on slide 3 present. Two font warnings reviewed.
Visual: all 8 slides rendered with [renderer] and inspected; corrected clipped label on slide 6 and regenerated its preview.
PowerPoint: not available in this environment; opening, editing, and playback remain unverified.
```

This is an illustrative report, not a result to copy without performing the checks. A ZIP package containing a chart is only structural evidence. A screenshot is only evidence of the renderer's visible output. Actual PowerPoint opening does not by itself verify every chart's data or every media object's playback.

For a review-only request, present findings without silently modifying the source. For an authorized build or edit, resolve relevant findings, then deliver the final file and describe any remaining material gap.
